# 关闭重网格时的派生场刷新修正

`AdvancePhiAtLevel` 原先用 `(step + 1) % regrid_int == 0` 判断是否更新涡量/压力。强、弱扩展输入设 `amr.regrid_int=-1`；任意整数对 `-1` 取余均为 0，所以该分支每步执行 `UpdateDerivedMacroFields()`，并在其中再次 `FillPatchMacro`。这与负值关闭重网格的含义不符，也给无输出基准引入多余通信。

现仅在正的重网格、绘图或检查点间隔到期时刷新派生场。后两种条件保留输出时宏观派生量的时效性；常规密度、速度和分布函数的推进公式未变。1/2/4 GPU 上 128³、10 步的密度、三个速度及 19 个分布函数的最终求和、二范数和极值均与原版逐项一致，见[紧凑场结果](derivedfix-field-summary-128.json)。测试关闭 plotfile/checkpoint，未写全场数据。该统计不证明全场逐位一致。

在相同 Open MPI 4.1.8 CUDA-aware `smcuda`、关闭 CUDA IPC、2 MiB 片段的单轮 256³ 强扩展中，修正前 1/2/4 卡为 50.887/31.918/24.907 ms/步，修正后为 **47.759/28.238/24.299** ms/步。每卡 256³ 弱扩展中，修正前为 50.891/54.467/73.924，修正后为 **46.847/48.776/70.786** ms/步。新代码的双/四卡强效率约 **84.6% / 49.1%**，弱效率约 **96.0% / 66.2%**；只有双卡弱扩展在这一次试验中高于 90%。[强扩展原始数据](derivedfix-strong-frag2048-r1.json)与[弱扩展原始数据](derivedfix-weak-frag2048-r1.json)记录二进制、输入和日志校验值。数据仅为单轮筛选，需三轮交错复测。

另试将同一格点的 streaming 与宏观量恢复融合为一个 GPU kernel；1/2/4 卡的紧凑场统计仍一致，见[数值结果](fused-field-summary-128.json)，但强扩展变为 46.198/30.017/24.058 ms/步，双卡明显慢于仅修正派生场的版本，四卡几乎没有收益。因此融合改动已撤销，只保留派生场条件修正；[融合计时](fused-strong-frag2048-r1.json)。
